# 🔥 Firefly — Módulo Java

**Algoritmo de análise preditiva para apoio à decisão em operações de resgate emergencial**

Este módulo contém a implementação em Java do Firefly, um algoritmo de análise preditiva que avalia cenários de resgate (bombeiros, SAMU e Defesa Civil) e recomenda ações com base em um Processo de Decisão de Markov (MDP) simplificado.

---

## 📌 Sobre o Módulo

A camada Java é responsável pela modelagem orientada a objetos do domínio do problema: estados, ações, agentes e regras de negócio da operação de resgate, seguindo princípios de Domain Driven Design (DDD).

Desenvolvido como parte do Global Solution 2026/1 da FIAP.

---

## 🛠️ Tecnologias

- Java (Programação Orientada a Objetos)
- Modelagem UML em Astah (diagramas de classe)
- Aplicação de interfaces e composição
- Domain Driven Design (DDD)

---

## 🧩 Estrutura

- Classes de domínio representando entidades da operação (cenário, agente, ação, estado)
- Interfaces para desacoplamento entre regras de decisão e execução

---

## 👥 Equipe

Projeto desenvolvido em equipe de 5 integrantes, com este módulo focado na modelagem e lógica de negócio em Java.
